📖 Простая инструкция

Как получить автономный файл программы

1

Скачайте файлы проекта

Вам нужно скачать все файлы программы на компьютер. Нажмите кнопку "Download" или "Скачать" в интерфейсе этой программы (обычно вверху страницы или в меню).

Сохраните ZIP-архив в удобное место, например на Рабочий стол.

2

Распакуйте архив

Найдите скачанный ZIP-файл на Рабочем столе. Правый клик → Извлечь все (или Распаковать).

Распакуйте в любую папку, например C:\РЗА

3

Откройте командную строку в папке

Откройте распакованную папку. В адресной строке проводника (где написан путь к папке) сотрите всё, напишите:

cmd

и нажмите Enter

Откроется чёрное окно — это командная строка.

4

Установите компоненты

В чёрном окне введите команду:

npm install

Нажмите Enter и подождите 1-2 минуты. Появится много текста — это нормально.

5

Соберите программу

В том же чёрном окне введите:

npm run build

Нажмите Enter. Через несколько секунд появится папка dist.

6

Готово! 🎉

Откройте папку dist. Внутри будет файл index.html — это ваша программа!

Переименуйте его в Планирование_РЗА.html и можете перенести куда угодно.

Открывайте двойным кликом — работает без интернета!

⚠️ Важно

  • Эти шаги нужно выполнить только один раз
  • После сборки файл index.html полностью автономен
  • Папки node_modules и src можно удалить — они больше не нужны
  • Данные хранятся в браузере, делайте резервные копии через "Экспорт в Excel"
