📖 Инструкция по сборке программы

Как получить автономный файл программы

1

Установите Go (язык программирования)

Скачайте и установите Go с официального сайта:

🔗 Скачать Go

При установке оставляйте все настройки по умолчанию. После установки перезагрузите компьютер.

2

Найдите папку rza-go

В этой папке находятся файлы программы:

  • main.go — код программы на Go
  • index.html — интерфейс программы
  • СОБРАТЬ.bat — скрипт для сборки
3

Запустите сборку

Дважды кликните по файлу СОБРАТЬ.bat

Откроется чёрное окно. Подождите 10-20 секунд, пока программа соберётся.

Когда появится сообщение "Готово!" — нажмите любую клавишу.

4

Готово! 🎉

В папке появится файл Планирование_РЗА.exe

Это ваша программа! Можете:

  • Запустить двойным кликом
  • Перенести в любую папку
  • Создать ярлык на рабочем столе

✅ Программа работает БЕЗ интернета!

⚠️ Важно

  • Шаги 1-3 нужно выполнить только один раз
  • После сборки файл .exe полностью автономен
  • Папку rza-go можно удалить после сборки
  • Данные хранятся в браузере, делайте резервные копии через "Экспорт в Excel"

🆘 Не получается?

Если что-то не получается, покажите эту инструкцию любому знакомому, кто разбирается в компьютерах. Он поможет выполнить шаги 1-3 за 2 минуты.

Или напишите мне — я постараюсь помочь!
